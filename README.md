# 🗂 Kanban Board — React + TypeScript

Projeto de um quadro Kanban desenvolvido com foco em boas práticas
de front-end e simulação de demandas reais de mercado.

## 🚀 Tecnologias
- React + TypeScript
- Vite
- Tailwind CSS
- Context API
- LocalStorage
- HTML Drag and Drop API

## ✨ Funcionalidades
- Criar, editar e remover cards
- Persistência de dados no navegador
- Drag and drop entre colunas
- Arquitetura baseada em estado global
- Código organizado e tipado

## 🧠 Decisões técnicas
- Context API para estado global simples
- Persistência via localStorage sem backend
- Drag & drop nativo para evitar libs desnecessárias
- Estrutura pensada para testes técnicos
